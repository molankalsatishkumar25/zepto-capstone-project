# Zepto Data & AI Platform

Capstone project for building a connected Data Pipeline, Analytics & Machine Learning solution, and Zepto Support Assistant.

## Project Overview

This repository contains three connected modules:

1. **Data Pipeline** — Web scraping, cleaning, enrichment, SQLite storage, SQL validation, and Pandas-based validation.
2. **Analytics & Machine Learning** — Titanic dataset EDA, preprocessing, classification, imbalance handling, and regression.
3. **Zepto Support Assistant** — Local document retrieval, intent classification, LangGraph workflow, Pydantic responses, and FastAPI API.
